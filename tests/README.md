# Проверки Frontline WASD

Запуск из корневой папки: `npm test`. Дополнительные пакеты не нужны.

- objectives.cjs: 1v1, турели и окружение, захват/XP/обзор/ожидание, сетевой обзор, стороны и запас HE.
- client-smoke.cjs: загрузка клиента, обновление интерфейса и отрисовка с тестовым окружением; это не визуальная проверка в браузере.
- network-lobby.cjs: локальный HTTP-сервер, четыре игрока, выбор и смена сторон, готовность, потоки состояния, старт, перезапуск и переподключение.
