# FRONTLINE — версия 13 / Radmin 1v1

Игра поддерживает одиночную тренировку с переключением сторон по Y и сетевой матч NATO против Soviet. Центральная нейтральная сторона — FIA. Для игры вдвоём сервер запускается на компьютере хозяина; другу нужны Radmin VPN и браузер.

В версии 13: снаряды имеют 37,5% исходной скорости, весь AP-урон удвоен, башни стоят снаружи ромба, дым имеет восстанавливаемый бак, ремонт лечит 20 HP/с, прогрессия расширена до 9-го уровня. Инструкция подключения ниже не изменилась.

## Изменения версии 13

Над танками остаётся только обозначение тира брони. В сетевой игре цвета зависят от игрока: союзники синие, враги красные; корпус, башня, полоса HP, базы, пехота и миникарта используют одно правило. В одиночной игре цвета NATO/Soviet не меняются при Y: оба корпуса зелёные, башня NATO синяя, башня Soviet красная. FIA остаётся нейтрального цвета.

Пушки линейных башен, центральной турели и обе пушки каждой базы поворачиваются с ограничением 60°/с. Стрельба разрешена только после наведения. После начала огня по танку сохраняется прежнее удержание цели.

Скорость всех пуль и снарядов составляет 37,5% от первоначальной, то есть половину значения версии 12. Время существования продлено для сохранения дальности.

Танк без стабилизации преследует выходящую из радиуса цель, останавливается и делает короткую паузу перед выстрелом. Стрелять в движении или при вращении корпуса можно только с улучшением «Стабилизация» на 9-м уровне. Уже выпущенные снаряды продолжают лететь после начала движения. Прямой приказ атаковать сохраняет преследование; огонь при самостоятельном движении работает по целям в радиусе. S сбрасывает движение и атаку.

## 1. Что скачать

На компьютере, который будет сервером:

1. Скачайте архив `frontline-radmin.zip` и полностью распакуйте его в отдельную папку. Не запускайте файлы прямо из ZIP.
2. Установите Node.js LTS с https://nodejs.org/en/download . На странице выбирайте Windows Installer и версию LTS. После установки заново откройте папку игры. Установка пакетов через npm не требуется.
3. Установите Radmin VPN с https://www.radmin-vpn.com/ .

На компьютере друга:

1. Установите Radmin VPN с того же официального сайта.
2. Node.js и архив игры другу не нужны: страницу и файлы игры он получит с вашего компьютера.

Нужен именно Radmin VPN. Программа удалённого управления Radmin Server для этой игры не требуется.

## 2. Создать общую сеть Radmin

На компьютере хозяина:

1. Откройте Radmin VPN.
2. Нажмите «Сеть» → «Создать сеть» (Create network).
3. Придумайте имя сети и пароль.
4. Передайте другу имя и пароль сети личным сообщением.

У друга:

1. Откройте Radmin VPN.
2. Нажмите «Сеть» → «Присоединиться к сети» (Join network).
3. Введите то же имя сети и пароль.
4. Убедитесь, что вы видите друг друга в списке участников, оба включены и доступны.

В Radmin VPN найдите IPv4 компьютера хозяина. Обычно адрес начинается с `26.`. Нужен адрес хозяина, а не адрес друга, не обычный домашний `192.168...` и не localhost.

Проверить соединение можно командой Ping из контекстного меню компьютера в Radmin VPN. Отсутствие ответа не всегда означает неисправность: отдельные правила Windows могут блокировать ping. Главная проверка — открывается ли страница игры у друга.

## 3. Запустить игровой сервер

На компьютере хозяина:

1. В распакованной папке дважды нажмите `START-SERVER.cmd`.
2. Откроется окно сервера. Оставьте его открытым на всё время игры.
3. Найдите строку `MATCH CODE: 123456`. Цифры будут другими при каждом новом запуске сервера.
4. Найдите ссылку `HOST: http://localhost:8765`.
5. В строках `FRIEND:` сервер выводит доступные адреса вашего компьютера. Выберите тот адрес, который совпадает с IPv4 в Radmin VPN.

Пример, НЕ ваш фактический адрес: если Radmin показывает `26.12.34.56`, друг открывает `http://26.12.34.56:8765`.

Пароль сети Radmin и MATCH CODE — разные вещи. Пароль соединяет компьютеры в VPN. MATCH CODE позволяет занять место игрока в матче.

Если окно пишет, что Node.js не найден, установите Node.js LTS и заново запустите файл. Если написано, что порт 8765 занят, закройте другое окно игрового сервера и повторите запуск.

## 4. Разрешить подключение в Windows

Если Windows при запуске покажет запрос на доступ для Node.js, разрешите входящие подключения в доверенной сети, которую используете для Radmin VPN.

Если у хозяина игра открывается, а у друга нет, добавьте узкое правило вручную на компьютере хозяина:

1. Нажмите Win + R, введите `wf.msc`, нажмите Enter. Может потребоваться разрешение администратора.
2. Слева выберите «Правила для входящих подключений», справа — «Создать правило».
3. Тип правила — «Для порта».
4. Протокол — TCP, определённый локальный порт — `8765`.
5. Действие — «Разрешить подключение».
6. Отметьте профиль, соответствующий подключению Radmin. Если профиль неизвестен, можно применить правило ко всем профилям, затем обязательно ограничить удалённый адрес следующим шагом.
7. Назовите правило `FRONTLINE Radmin 8765` и завершите мастер.
8. Откройте свойства созданного правила → «Область» → «Удалённые IP-адреса» → «Указанные IP-адреса» → «Добавить».
9. Впишите IPv4 ДРУГА из Radmin VPN. Это адрес друга, а не хозяина. Сохраните правило.

После этого повторите открытие ссылки у друга. Брандмауэр целиком выключать не нужно. Проброс портов на роутере для подключения внутри Radmin VPN не требуется. Эта сборка рассчитана на игру внутри вашей VPN, а не на публикацию сервера в открытый интернет.

## 5. Подключиться к одному матчу

Хозяин:

1. Откройте в браузере `http://localhost:8765`.
2. Нажмите «Сетевая игра 1v1».
3. Введите MATCH CODE из окна сервера и нажмите «Подключиться».
4. Первый подключившийся получает NATO (синих). Появится «Ожидаем второго игрока…».

Друг:

1. Откройте браузером ссылку хозяина из Radmin, например `http://26.12.34.56:8765` (пример, подставьте настоящий адрес).
2. Нажмите «Сетевая игра 1v1».
3. Введите тот же MATCH CODE и нажмите «Подключиться».
4. Второй подключившийся получает Soviet (красных).

Когда оба подключены, появляется сообщение «Оба игрока подключены · матч идёт». Волны, попадания, опыт, базы и захват центра общие. Каждый игрок видит мир с учётом обзора своей команды и имеет собственные улучшения и перезарядку.

Не открывайте опубликованную одиночную ссылку для матча через Radmin: оба должны открыть именно страницу с локального игрового сервера хозяина. Используйте HTTP, не HTTPS.

Для проверки на одном компьютере можно подключить две отдельные вкладки: одну первой, вторую второй, введя одинаковый код. У каждой вкладки будет свой танк.

## 6. Управление

- ЛКМ по земле — движение задним ходом к точке; базовая скорость вдвое ниже переднего хода. ПКМ по земле — движение вперёд. ПКМ по врагу, башне, базе или турели — атака.
- После уничтожения цели танк выбирает ближайшего врага в радиусе.
- Alt + ПКМ по союзнику — намеренный приказ атаковать его. Случайные попадания тоже наносят дружественный урон.
- 5 — активный ремонт; повторное нажатие отменяет его за 2 секунды.
- 1 — AP, 2 — HE, 3 — MG. Смена оружия занимает 1 секунду.
- Удерживайте 4 или экранную кнопку Smoke — подача дыма позади танка. Если последним нажатием оружия уже был Smoke, повторный дым включается без задержки переключения. Нажатие 1–3 сбрасывает это исключение.
- S — остановить танк и отменить атаку; R — показать или скрыть дальность и обзор. M — общий вид карты. Y — сменить сторону в одиночной тренировке (в сетевом матче отключено).
- Улучшения выбираются внизу по центру без паузы. Очередь невыбранных улучшений сохраняется.
- В сетевой игре ручная пауза отключена. Если один игрок потерял связь, симуляция автоматически останавливается.

## 7. Актуальная игровая механика версии 13

### Карта и стороны

Мир 2400 × 1400, две основные линии образуют ромб. Камера следует за танком; M показывает всю карту. Y переключает управление и обзор между NATO и Soviet в одиночной тренировке. В сетевом матче Y отключено.

Основные линии дают 100% скорости, грунтовые дороги — 85%, трава — 70%. Пехота не участвует в выборе маршрута танка: он раздвигает союзников и врагов на пути. В плотной группе сохраняется дополнительное замедление 30%. Базовый задний ход — 50% переднего. Оба направления учитывают постепенный поворот корпуса 55°/с; движение начинается при отклонении от курса до 30°. Башня танка поворачивается 60°/с и смещена к корме на 8 единиц.

### Башни и базы

У каждой стороны по две башни на каждой линии. Они стоят вплотную к внешней кромке ромба. Внешняя относительно базы башня №1: броня I, 1500 HP, AP 144 урона раз в 3,2 с. Башня №2: броня II, 2000 HP, AP 192 урона раз в 2,4 с. Их MG по пехоте сохранён: 7 урона раз в 0,22 с. Дальность 300, обзор 340.

Базы: 2000 HP, броня III, две независимые пушки. Каждая использует MG 7 урона / 0,2 с по пехоте и AP 300 урона / 1,8 с по технике. Дальность 260. При уничтожении базы матч заканчивается.

Центральная FIA: 650 HP, броня II, дальность 280, обзор 370, AP 40 урона раз в 1,2 с. После уничтожения танк может захватить её за 6 с в круге радиуса 95. Два танка в круге останавливают захват; пустой круг медленно теряет прогресс. Союзная турель восстанавливается; находящиеся внутри юниты перемещаются на свободное место. За нанесённый ей урон опыта нет; за добивание нейтральной или вражеской центральной турели — 200 XP.

Если башня, турель FIA или пушка базы уже выстрелила в танк, она удерживает его целью до смерти или выхода из радиуса. Более близкая пехота не перехватывает внимание. Дым может перекрыть огонь, но не сбрасывает цель, пока танк остаётся в радиусе. У каждой пушки базы собственное удержание цели.

### Вооружение и пехота

Танк: 700 HP, броня III. AP — 96 базового урона; HE — 36 урона, взрыв радиусом 40; оба имеют интервал 2,4 с до улучшений скорости атаки. MG — 5 урона / 0,12 с. Скорость полёта всех пуль и снарядов теперь 37,5% исходной (вдвое ниже версии 12); время их существования увеличено для сохранения дальности.

Смена оружия занимает 1 с до соответствующего улучшения. Время смены AP ↔ HE равно двум текущим интервалам стрельбы (с учётом скорости атаки). Улучшение 8-го уровня уменьшает множитель с 2 до 1. Обычная зарядка после выстрела занимает один интервал. Мгновенное переключение оружия не отменяет смену снаряда.

Волны каждые 20 секунд на обеих линиях: 2 обычных пехотинца, 1 HAT, 1 снайпер. LAT удалён. Снайпер: 65 HP, дальность 168,75 (на 25% больше обычных 135), базовый урон 24, интервал 2,8 с. HAT против пехоты использует обычное оружие, против техники и сооружений — AP 96 урона раз в 2,4 с. AP HAT одинаков у обеих сторон. У обычного оружия пехоты Soviet временно сохраняется +50% урона.

Все снаряды пехоты проходят сквозь союзников и союзные сооружения. Дружественный огонь танков и башен сохранён: штраф игроку −10% фактически нанесённого союзникам урона в XP, при добивании ещё −40 XP. Опыт не ниже нуля, достигнутые уровни не отзываются.

### Ремонт и дым

Пассивная регенерация: 1 HP/с после 10 секунд без полученного урона. Активный ремонт на 5: сначала 5 с подготовки, затем 20 HP/с. Пассивная регенерация складывается с активной, когда выполнено условие 10 с без урона. Круг вокруг танка показывает подготовку; ключ — активную фазу. Улучшение 7-го уровня сокращает подготовку до 3 с.

Попытка действия прекращает активное лечение и запускает отмену на 2 с, после которой выполняется последний приказ. Повторные приказы не продлевают задержку. Попадание во время подготовки, лечения или отмены прерывает ремонт и оглушает на 3 с. Просмотр карты и смена камеры не являются приказами танку.

Бак дыма — 100%. Подача расходует 10%/с, вне подачи восстанавливается 2%/с. Полного бака хватает на 10 с подачи; на пустом баке подача прекращается. На возрождении бак заправлен полностью. Расход идёт только во время фактической подачи, без затрат в задержке переключения. Удерживайте 4 или Smoke. Дым выходит позади танка, сгущается при накоплении на месте и блокирует обзор после достижения порога концентрации 1,2. Улучшение 6-го уровня снижает требуемый порог до 0,9. Союзные наблюдатели сбоку или за завесой сохраняют свой обзор. Повторный Smoke не требует задержки переключения, если последним нажатием оружия был Smoke.

### Броня

Тир 0: полный урон, уклонение от MG 10%, от AP 25%; HE-взрыв не уклоняется. Тир I: HE ×0,50, AP ×1, MG ×0,75. Тир II: HE ×0,25, AP ×0,75, MG ×0,50. Тир III: HE ×0,10, AP ×0,50, MG ×0,25. Корпус танка после расчётов и улучшений дополнительно снижает урон: лоб на 50%, борта на 25%, корма без базового снижения. При уклонении снаряд продолжает лететь.

### Уровни 1–9

Пороги уровней 2–9: 1200 / 3600 / 7200 / 12000 / 18000 / 25200 / 33600 / 43200 общего XP. Для каждого следующего уровня нужно 1200 / 2400 / 3600 / 4800 / 6000 / 7200 / 8400 / 9600 XP — арифметическая прогрессия. Выбор улучшений без паузы, невыбранные уровни ждут своей очереди.

- Уровень 1: +60% урона HE / +10% урона AP
- Уровень 2: +10% брони спереди / +4% по бокам, +2% сзади
- Уровень 3: +10% дальности атаки / +10% дальности обзора
- Уровень 4: +25% скорости снаряда / +10% скорости движения
- Уровень 5: +25% скорости атаки / +50% скорости поворота пушки
- Уровень 6: +25% скорости поворота корпуса / −25% концентрации для дыма
- Уровень 7: Подготовка ремонта за 3 с / Без задержки переключения оружия
- Уровень 8: Смена снаряда за 1 интервал / +100% скорости пуль и снарядов
- Уровень 9: Стабилизация: стрельба на ходу / Задний ход в 2 раза быстрее переднего

Улучшение стрельбы на ходу начинает автоатаку после первого выстрела: танк продолжает стрелять при движении и после гибели цели выбирает ближайшую в радиусе. Когда целей нет или нажат S, автоатака прекращается. До этого улучшения приказ движения прерывает стрельбу. Альтернатива 9-го уровня устанавливает задний ход в 200% переднего — это вчетверо быстрее базового заднего хода.

Опыт за фактический урон и добивание обычных крипов ×1, HAT ×1,30, снайпера ×1,20. Бонус добивания до множителя — 15 XP. За танки и остальные сооружения положительный XP пока не даётся.

## 8. Переподключение и новый матч

При кратком обрыве связи браузер пробует переподключиться автоматически, а матч ждёт обоих игроков. Вернитесь в прежнюю вкладку. После обновления страницы снова нажмите «Сетевая игра 1v1» и введите код; в той же вкладке место игрока восстановится.

После завершения матча первый подключившийся игрок (NATO) может нажать «Заново»: матч сбросится для обоих. Игроку Soviet эта кнопка недоступна.

Если игрок окончательно закрыл вкладку и прежняя сессия потерялась, проще остановить сервер Ctrl + C, запустить заново и подключить обоих с новым MATCH CODE. Новый запуск всегда создаёт чистый матч. Чтобы закончить игру, закройте окно сервера или нажмите в нём Ctrl + C.

## 9. Если друг не подключается

- Сначала хозяин проверяет `http://localhost:8765`. Если не открывается — сервер не запущен, завершился с ошибкой или порт занят.
- Если хозяин видит игру, а друг нет — проверьте общую сеть Radmin, доступность компьютеров, IPv4 хозяина, порт 8765 и входящее правило Windows. Друг не должен вводить localhost: он означает компьютер самого друга.
- Если страница открывается, но код не подходит — используйте текущий MATCH CODE из текущего окна сервера. Это не пароль Radmin.
- «Оба места уже заняты» — вернитесь в прежнюю вкладку. Для совершенно нового подключения перезапустите сервер.
- «Ожидаем второго игрока» — друг ещё не нажал «Подключиться» или использует опубликованную одиночную страницу вместо локального адреса хозяина.
- «Соединение игрока потеряно» — проверьте Radmin и вкладку второго игрока. После восстановления связи матч продолжится.
- Сторонний антивирус может отдельно блокировать входящий TCP 8765. Разрешите только этот порт и адрес друга, не отключая защиту целиком.

## Проверенные границы

Симуляция, два независимых сетевых клиента и вход двух браузерных вкладок проверены на одном компьютере. Соединение между вашими двумя физическими компьютерами через Radmin нужно проверить у вас: оно зависит от сети, настроек VPN и брандмауэра.
