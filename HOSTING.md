# Хостинг FRONTLINE для игры Казахстан — Словакия

Начать можно с Render Web Service во Frankfurt. Альтернатива — Railway в Amsterdam. Регион стоит проверить обоим игрокам: расстояние и маршруты провайдеров влияют на задержку. На отдельном сервере вы оба будете клиентами; Radmin не нужен.

## Render
1. Загрузите содержимое папки Frontline в свой Git-репозиторий: dist/, server.cjs, package.json. Не загружайте backup-before-… и .git старого проекта.
2. На Render выберите New → Web Service и подключите этот репозиторий.
3. Region: Frankfurt. Runtime: Node. Build Command: npm install --omit=dev. Start Command: npm start.
4. Используйте один экземпляр сервера (1 instance): матч хранится в памяти этого процесса. Для постоянной игры подойдёт платный сервер; минимальная вычислительная конфигурация сейчас стоит $7/месяц, трафик сверх включённого оплачивается отдельно. Бесплатный вариант пригоден для проб: может перезапускаться и засыпает после простоя.
5. В Environment добавьте FRONTLINE_CODE — ваш код матча (лучше длинная комбинация букв и цифр, не более 24 символов, как допускает поле входа). Код передайте другу. PORT задаётся платформой автоматически; игра его поддерживает.
6. После запуска откройте адрес https://…onrender.com. Оба игрока открывают ОДИН И ТОТ ЖЕ адрес, выбирают «Сетевая игра 1v1» и вводят FRONTLINE_CODE. Первый — NATO, второй — Soviet. Затем каждый выбирает технику и нажимает «Подтвердить выбор». Матч ждёт оба подтверждения.
7. balance.js меняйте в репозитории и публикуйте новую версию между матчами. Перезапуск или повторная публикация начинают новый матч.

## Railway
Загрузите тот же проект, выберите EU West Metal (Amsterdam), команду npm start и один экземпляр. Задайте FRONTLINE_CODE и включите публичный HTTPS-домен. План Hobby сейчас стоит $5/месяц и включает $5 ресурсов; превышение оплачивается отдельно. Это не фиксированный предел итогового счёта.

## Почему не Netlify целиком
Игра использует постоянно работающий процесс Node.js, состояние матча в памяти и поток SSE. Netlify Functions ограничены временем выполнения (сейчас 60 секунд для обычных и потоковых ответов). Статическую страницу можно разместить там отдельно, но для текущей версии проще держать страницу и сервер вместе на Render/Railway.

Два игрока могут проверить один и тот же сервер по HTTPS до выбора платного тарифа. Само размещение не гарантирует конкретный пинг. Помимо сети в игре есть буфер сглаживания около 100 мс.

## 2v2
Один сервер поддерживает комнату 1v1 или 2v2. Первый вход определяет режим; всем нужно нажать одинаковую кнопку. Для 2v2 нужны четыре одновременных соединения. Игроки входят в порядке NATO, Soviet, NATO, Soviet. Матч ждёт готовности всех четырёх и приостанавливается при отключении любого. Новых переменных окружения или зависимостей не требуется.
